# Daycare Notification App

A real-time messaging application built for daycare centers to streamline communication between teachers/owners and parents.

## 🚀 Tech Stack

- **Frontend:** React (Vite)

- **Backend/Database:** Supabase (PostgreSQL)

- **Real-time:** Supabase Broadcast Channels
